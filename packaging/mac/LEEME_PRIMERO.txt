CALCULA TU HUELLA · DEMO FULL AUTOCONTENIDA PARA macOS
=====================================================

Esta distribución incluye:
- código completo del commit de release identificado en BUILD_PROVENANCE.json;
- CPython 3.12 portable fijado para Apple Silicon (arm64) e Intel (x86_64);
- dependencias Python bloqueadas con hashes y wheelhouse offline para ambas arquitecturas;
- migraciones completas y base demo persistente;
- lanzadores para instalar, abrir, cerrar, reiniciar y verificar;
- manifiestos SHA-256 del contenido y del artefacto final.

V2.0 · ESTABILIDAD Y READINESS
- El paquete incorpora exactamente el runtime del commit declarado en BUILD_PROVENANCE.json.
- El arranque local no depende de una comprobación de Storage externo antes de abrir el puerto.
- /api/health funciona como liveness ligero.
- /api/ready mantiene el diagnóstico estricto de dependencias y puede responder 503 cuando una dependencia externa está degradada.
- Los controles de Storage S3 usan timeouts y reintentos acotados; una configuración inválida falla antes de tocar red.

INSTALACIÓN
1. Descomprime el ZIP completamente.
2. Abre la carpeta resultante.
3. Haz doble clic en: 1_INSTALAR_Y_ABRIR_DEMO.command
4. Si macOS bloquea el primer inicio: clic derecho > Abrir > Abrir.
5. El instalador detecta automáticamente Apple Silicon o Intel.
6. No necesita Homebrew, VS Code ni Python instalado.
7. No necesita internet para instalar dependencias.
8. Antes de instalar, el lanzador verifica MANIFEST_SHA256.txt y falla si el paquete fue alterado.

TRAZABILIDAD
- BUILD_PROVENANCE.json identifica commit, runtime y lock usados.
- PYTHON_RUNTIME_ORIGEN.json registra los dos binarios de Python y sus SHA-256.
- WHEELHOUSE_SHA256.txt registra cada wheel incluido.
- MANIFEST_SHA256.txt permite verificar todos los archivos internos.
- El ZIP se publica junto con RELEASE_MANIFEST.json y su archivo .sha256.
