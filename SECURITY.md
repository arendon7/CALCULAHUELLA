# Seguridad · V1.0.0

- Las cuentas y la contraseña `Demo2026!` son exclusivamente demostrativas.
- Una instalación productiva debe usar `SEED_DEMO=false`, contraseñas únicas, secretos externos y HTTPS.
- El instalador no incluye bases reales, tokens ni certificados generados durante las pruebas.
- Evidencias y certificados utilizan SHA-256 para comprobar integridad.
- Los respaldos y certificados se conservan fuera de la carpeta reemplazable del código.
- La aprobación para producción no puede concederse si faltan servicios externos o secretos obligatorios.
