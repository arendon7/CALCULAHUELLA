# V0.45.5 · Importación y corrección guiada

## Objetivo
Reducir la fricción entre recibir un archivo operativo y disponer de un lote listo para aplicación.

## Capacidades
- Lectura configurable de CSV y XLSX.
- Selección de hoja y fila real de encabezados.
- Detección o selección del separador CSV.
- Mapeo asistido con control de campos mínimos.
- Validación previa sin afectar el inventario.
- Corrección individual de fuente, periodo, valor, unidad, origen, evidencia y condición estimada.
- Revalidación inmediata y cierre trazable de hallazgos previos.

## Invariantes
No se modificaron factores de emisión, conversiones, reglas metodológicas, modelos de base de datos ni migraciones.
