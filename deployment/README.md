# Despliegue · V0.53.0

La distribución principal de Calcula tu Huella V0.53.0 es local y autocontenida para macOS y Windows. Los archivos de esta carpeta sirven para ensayos controlados con Docker, PostgreSQL y proxy; no son necesarios para el uso local básico.

La operación productiva requiere infraestructura, secretos, correo, almacenamiento, copias de seguridad y monitoreo reales.
