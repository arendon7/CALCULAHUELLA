# Uso en Windows · V1.0.0 · candidata de lanzamiento

1. Ejecuta `1_INSTALAR_Y_ABRIR.bat` para la instalación local.
2. Ejecuta `4_PREPARAR_PRODUCCION.bat` para generar la plantilla productiva y el diagnóstico.
3. La distribución local usa SQLite; producción requiere PostgreSQL, almacenamiento externo y SMTP.
4. El instalador debe ensayarse físicamente en Windows 10 y 11 antes de una publicación real.
