# Uso en Windows · Calcula tu Huella V1.0.0

## Instalación

1. Extrae completamente la carpeta `WINDOWS`.
2. Ejecuta `1_INSTALAR_Y_ABRIR.bat`.
3. Usa `2_ABRIR_CALCULA_TU_HUELLA.bat` para volver a abrir.
4. Los datos se conservan bajo `%LOCALAPPDATA%\CalculaTuHuella`.

## Validación

Ejecuta `5_VALIDAR_VERSION_FINAL_V1.bat`.

## Prueba física

Antes de distribuir el instalador a terceros, completa `FORMATO_PRUEBA_WINDOWS_V1.md` en Windows 10 y Windows 11.

## Producción

Consulta `GUIA_PRODUCCION_V1_FINAL.md`. El núcleo Windows es el mismo que Mac, pero la compatibilidad del instalador debe comprobarse en equipos reales.
