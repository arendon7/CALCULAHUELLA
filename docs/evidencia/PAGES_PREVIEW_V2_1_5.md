# GitHub Pages · Living Preview V2.1.5

`main/site` funciona como superficie pública de preview y puede recibir sincronizaciones controladas de `site/` desde la línea activa sin promover el backend, migraciones, cálculos ni infraestructura productiva.

La demo de plataforma publicada en Pages es HTML/CSS/JS estático con datos demostrativos y `localStorage`; no sustituye la aplicación FastAPI ni debe interpretarse como entorno productivo.
