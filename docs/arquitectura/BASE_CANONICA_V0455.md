# Base canónica v0.45.5

Se compararon los árboles v0.45.2, v0.45.3, v0.45.4 y v0.45.5. La v0.45.5 contiene todos los archivos funcionales de las versiones anteriores. Las diferencias exclusivas eran cachés, bytecode o manifiestos de entrega.

La migración conserva código, plantillas, recursos estáticos, migraciones, pruebas, documentación, Docker y scripts macOS. Se excluyen bases locales, secretos, evidencias, reportes generados, respaldos, logs, cachés y ZIP de distribución.
