# Archivo histórico excluido de la raíz canónica

La Iteración 14 contenía numerosos documentos y manifiestos de versiones V0.x, además de dos copias completas del código para Mac y Windows. Esos elementos no se copiaron a la raíz canónica porque producían duplicidad y dificultaban el mantenimiento.

La trazabilidad relevante se conserva en `docs/auditorias`, `docs/gobierno`, `docs/evidencia` y el historial Git. El ZIP original de la Iteración 14 debe conservarse como archivo histórico independiente.
