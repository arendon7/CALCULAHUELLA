# Declaración de versión canónica

> **Alcance de esta evidencia:** este documento conserva el snapshot histórico de canonicalización aprobado el 5 de agosto de 2026 para la versión técnica de aplicación `1.0.0`. No pretende describir el head web más reciente ni sustituye la evidencia posterior de CI/Render. La línea de certificación web V2.1.5 post-RC evoluciona de forma independiente y no implica por sí sola un cambio de versión semántica de la aplicación.

## Identidad

- Producto: Calcula tu Huella
- Versión de aplicación: 1.0.0
- Release canónica: `v1.0.0-canonica.20260805`
- Fuente inmediata: Iteración 14, formularios asistidos y lenguaje claro
- Fecha de corte: 5 de agosto de 2026

## Decisión de canonicidad

Este paquete reemplaza como referencia técnica a las carpetas duales duplicadas Mac/Windows. El código de aplicación, migraciones y pruebas se conserva una sola vez. Los elementos exclusivos de cada sistema operativo permanecen como lanzadores y scripts en la raíz.

## Alcance funcional preservado

Se preservan el motor metodológico, las 15 categorías de Alcance 3, tierras y remociones, huella de producto, proyectos de mitigación, aseguramiento, cinco empresas demo, navegación por roles, accesibilidad, lenguaje claro, respaldo, restauración y certificación multiempresa.

## Estado de liberación

Aprobada como base canónica para conservación, análisis y futura migración al repositorio. La publicación pública de la aplicación completa continúa condicionada a infraestructura backend, secretos, base de datos, almacenamiento, dominio, pruebas físicas y seguridad externa.
